### Hemlock Woolly Adelgid

This web map shows the distribution of reported Hemlock Woolly Adelgid (HWA) sightings in the eastern United States. Included data shows 21 states along with Washington D.C. based on data obtained from EDD MapS data from the Center for Invasive Species and Ecosystem Health at the University of Georgia. HWA infection is present in all states with Eastern and Carolina Hemlock populations except Indiana, where HWA has not been identified. 


Symbolization uses a yellow-green color ramp divided into 4 classes using the natural breaks method. Design includes basic information and a brief history on HWA. An image of an infested Eastern Hemlock is included.
